# TORCH_Light_Injection_Q125
3D CAD for assembly to inject light into TORCH project quartz plate.

Injects light into bottom of quartz plate used as a Cherenkov radiator in order to test/calibrate the photodetectors.

Used in beam tests at CERN T9 in Q1/Q2 2025

Initial design done in Autodesk Open Inventor. Final design (probably?) in SolidWorks

Two directories:
- Laser_Light_Injection_System (Final design by Keith Clarke, probably with SolidWorks. )
- Light Injection (Initial design by David Cussans. Turned out to be too wide to fit. )

There are two 3D printed pieces:
- Optics Housing - which houses a LC coupler , a mirror to reflect the light upwards , and a diffuser to scatter the light as widely as possible. Fixed to the base.
- Base - "U" shaped piece that fits underneath the bottom support for the quartz plate.

The overall design is shown in "Full Assembly V3"

Parts list:
- Molex 1061251100 LC-LC coupler
- Thorlabs MRA03-E02 3mm right angled mirror https://www.thorlabs.com/item/MRA03-E02
- Thorlabs DG05-220 1/2" ground glass diffuser https://www.thorlabs.com/item/DG05-220
